🌾 AgriYield Predictor: Forecasting Crop Yield Using Environmental and Soil Data
1. Abstract

Agriculture is one of the most important sectors contributing to the economy and food supply. Accurate prediction of crop yield can help farmers make informed decisions regarding crop selection, resource management, and planning.

The AgriYield Predictor is a machine learning-based system designed to forecast crop yield using environmental and soil parameters such as Nitrogen (N), Phosphorus (P), Potassium (K), temperature, humidity, rainfall, and soil pH.

The system uses the Random Forest Regression algorithm to provide accurate predictions. A user-friendly interface with sliders and dropdowns allows users to input values easily and obtain real-time predictions.

2. Introduction

Agriculture faces many challenges such as unpredictable weather conditions, soil degradation, and inefficient resource utilization. Traditional methods of predicting crop yield are often inaccurate and time-consuming.

This project introduces a smart solution using machine learning to predict crop yield efficiently. By analyzing soil nutrients and environmental conditions, the system helps farmers improve productivity and reduce risks.
